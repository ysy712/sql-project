# 智慧林草系统 - 数据库课程设计

## 项目简介
基于MySQL和Python Flask的智慧林草管理系统，实现环境监测、灾害预警、资源管理、设备管理和统计分析五大功能模块。

## 技术栈
- 后端：Python Flask + SQLAlchemy
- 前端：HTML + CSS + JavaScript + Bootstrap 5
- 数据库：MySQL 8.0
- 版本控制：Git + GitHub

## 开发环境搭建
1. 克隆项目：`git clone https://github.com/ysy712/sql-project.git`
2. 创建虚拟环境：`python -m venv venv`
3. 激活虚拟环境：
   - Windows: `venv\Scripts\activate`
   - Mac/Linux: `source venv/bin/activate`
4. 安装依赖：`pip install -r requirements.txt`
5. 配置数据库：修改`.env`文件中的数据库连接信息
6. 初始化数据库：`python database/init_db.py`
7. 运行应用：`python app.py`
